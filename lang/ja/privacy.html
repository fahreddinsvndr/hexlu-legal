Hexlu（以下「本ゲーム」）は、Pairo（以下「当社」）が配信するステンドグラスの光パズルです。このページでは、本ゲームが Android のスマートフォン・タブレットおよび iPhone・iPad で触れる情報、その受け取り先、そしてお客様が決められることをまとめています。

ひと目でわかる要点

  • アカウントもログインもありません。本ゲームが名前、メールアドレス、電話番号、写真を求めることはありません。
  • 進行状況、スター、コイン、設定はお使いの端末の中にあり、ほかの場所にはありません。
  • Google Firebase から利用統計、クラッシュレポート、遠隔で調整できるいくつかの設定を受け取り、ゲームを安定させてレベルを調整しています。
  • 広告は Google AdMob が表示します。法律で求められる地域では先に同意をお尋ねし、iPhone と iPad では広告 ID を使う前に OS も確認します。
  • 購入はそのつど Apple または Google が処理し、RevenueCat が記録します。カードや銀行の情報が当社に届くことはありません。
  • お客様のデータを金銭目的で販売することはなく、本ゲームが正確な位置情報、連絡先、カメラ、マイク、通知を必要とすることもありません。

ゲームが扱う情報

プレイヤー番号と端末の情報

Hexlu を初めて起動すると、お客様ご本人や端末とは結び付かない、ランダムな 8 文字のプレイヤー番号が作られます。Firebase（Analytics と Crashlytics）には、この番号が端末のモデル、OS のバージョン、言語、アプリのバージョン、メモリ容量とともに届き、RevenueCat は匿名の顧客 ID として使います。

利用統計（Firebase Analytics）

レベルを始めたとき・クリアしたとき、スターを集めたとき、ヒントやフェーズロックを使ったとき、デイリーパズルを開いたとき、画面を移動したとき、設定を変えたとき、広告を見たとき、何かを購入したときにイベントが記録されます。当社はこれをまとめて分析し、難しすぎる・易しすぎるレベルや、わかりにくい画面を見つけます。

クラッシュレポート（Firebase Crashlytics）

Hexlu がクラッシュしたり重大なエラーに遭遇したりすると、Crashlytics に技術的な詳細、端末の状態、画面名とボタンのタップだけで作られた短い操作履歴の直近の記録が届きます（入力した内容は含まれません）。「問題を報告」を選ぶと、同じ履歴を自分の意思で送信することになります。

起動時に取得する設定（Firebase Remote Config）

起動時に、ゲームは Firebase からいくつかの値を取得します。たとえば、サポート対象の最も古いアプリのバージョンや、広告を表示してよい頻度です。これらを届ける際にインストールを区別するため、Firebase はインストール識別子を割り当てます。

広告（Google AdMob）

Hexlu では、バナー広告とレベル間の広告、そして見るかどうかを選べるリワード広告が表示され、すべて Google AdMob によるものです。配信と効果測定のため、Google は端末の広告 ID（iPhone と iPad ではトラッキングを許可した場合のみ）、IP アドレス、そこから割り出した大まかな位置、広告への反応を受け取ります。同意の回答は Google の同意ツールによって端末に保存されます。広告を削除を購入した方には、バナー広告もレベル間の広告も表示されません。

購入（RevenueCat、Apple、Google）

コインや広告を削除を購入すると、支払いは Apple または Google が受け付けます。RevenueCat は、レシート、商品、プレイヤー番号、国、IP アドレスを受け取り、それをもとに購入を確認し、広告を削除を有効にし、ご要望に応じて復元します。

端末の外に出ないデータ

レベルの進行状況、スター、コインの残高、ヒント、デイリーパズルの状態、設定は、ゲームのローカルストレージにあります。当社のサーバーにはコピーがないため、内容を読み取ることはできず、新しいスマートフォンに自動で付いていくこともありません。

利用目的

  • ゲームの運営：遠隔の設定値、購入内容の有効化、アップデートのお知らせ。
  • 安定性の維持：クラッシュレポートと操作履歴。
  • 改善：レベル、ヒント、画面についてのまとめた数値。
  • 運営費の確保：Google が効果測定と不正対策を行う広告。

同意とお客様の選択

  • 同意メッセージ。欧州経済領域、英国、その他必要とされる地域では、広告が読み込まれる前に Google が同意メッセージを表示します。回答は、設定のプライバシーオプションからいつでも変更できます。
  • iPhone と iPad。iOS は、Hexlu が他社のアプリやサイトをまたいでお客様を追跡してよいかを尋ねます。拒否しても広告は表示されますが、広告 ID は使われません。あとから iOS の設定 > プライバシーとセキュリティ > トラッキングで変更できます。
  • Android。設定 > Google > 広告で、広告 ID のリセットや削除、広告のカスタマイズの停止ができます。
  • 広告を削除。この買い切りの購入で、バナー広告とレベル間の広告が表示されなくなります。リワード広告は常にお客様の自由で、見なくても何も失いません。
  • レポート。問題レポートは、お客様が送ると決めたときにだけ送信されます。

保存期間

Firebase Analytics はイベントデータを最長 14 か月間保持します。Crashlytics はクラッシュレポートを約 90 日間保持します。RevenueCat は、購入の復元や帳簿上の規則を満たすために必要な間、またはお客様が削除を求めるまで、購入記録を保持します。広告データは Google が自社の規約に従って扱います。

共有と国外への移転

情報が渡るのは、このページに記載したサービス提供者、つまり Google（Firebase と AdMob）と RevenueCat だけです。Firebase と RevenueCat は当社のために動き、Google は広告データを自社の広告サービスにも使います。そのうち複数の事業者が米国などでデータを処理しており、標準契約条項や EU-米国データプライバシーフレームワークなどの仕組みで裏付けています。お客様のデータが金銭と引き換えに誰かへ渡ることはありません。

お客様の権利

  • プレイヤー番号に紐づいて当社が保有している情報を確認し、その写しを受け取ること。
  • 訂正や削除、または利用の制限や停止を求めること。
  • いつでも同意を撤回すること（撤回前に行われた処理には影響しません）。
  • お住まいの地域のデータ保護当局に申し立てを行うこと。

アカウントがないため、お客様のデータを探す手がかりはプレイヤー番号だけです。「お問い合わせ」に記載のアドレスから、設定に表示される番号を添えてご連絡ください。30 日以内にお返事します。同じ手順はサポートページにもあります。

地域別の補足（GDPR、英国、カリフォルニア州）

GDPR および英国 GDPR のもとでは、広告 ID と広告の効果測定についてはお客様の同意に、統計とクラッシュレポートについては安定して改善され続けるゲームを提供するという当社の正当な利益に、購入についてはお客様との契約に、それぞれ基づいています。カリフォルニア州および米国の同様の州法では、ターゲティング広告のために広告 ID を Google と共有することが「共有」や「販売」にあたる場合があります。これは、ゲーム内のプライバシーオプション、端末の広告設定、またはメールでオプトアウトできます。当社は、知りながら個人データを金銭目的で販売することはなく、これらの権利を行使したことで不利益な扱いを受けることもありません。

お子様について

Hexlu は 13 歳以上のプレイヤーを想定して作られており、お子様を対象としていません。お子様が遊んでいるとお考えの場合はお知らせください。該当するデータを消去します。

セキュリティ

データは暗号化された通信で前述の事業者に送られます。完全に安全な通信方法はありませんが、当社は収集する情報を最小限にとどめ、アカウントもパスワードも保持しません。

本ポリシーの変更

ゲームが新しいサービスや新しい種類のデータを使い始める場合は、その変更がゲームに反映される前に、このページと上記の日付を更新します。重要な変更は、アップデートの案内でもお知らせします。
